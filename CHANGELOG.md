# Change Log

All notable changes to Docker Manager are recorded here.

## [0.5.3] - 19th October 2026

- Footer Stays at the Bottom of the Window
- Users Page – Add Local and Microsoft Users Side by Side, Shown Only When That Sign-In Is On
- Initials Ignore a Bracketed Company Name
- Delete User Shows the Email to Type in Full
- Profile Pictures – Microsoft Photo, or Gravatar for Everyone Else
- Mailcow Says What to Add When It Can't Reach the Server

## [0.5.2] - 19th October 2026

- Layout Check No Longer Flags the Dashboard's Own Registry Login Folder
- Dashboard Updates

## [0.5.1] - 19th October 2026

- Signing Out Returns to the Sign-In Page with a Note
- Download Button for Two-Step Recovery Codes
- QR Code Fills Its Box
- Dashboard Self-Update Page Refreshes by Itself When It's Back
- Build Pipeline Moved to Node 24 Actions

## [0.5.0] - 18th October 2026

- Watch Rules per Container – from Labels or the Dashboard
- Skip or Snooze an Update
- Release Notes Links
- Dashboard Filters and Search
- Random Start Delay, Check on Startup and Heartbeat Ping
- Layout Check – Flags Anything Kept Outside /docker

## [0.4.0] - 18th October 2026

- Notification Channels – Azure Communication Services, SMTP2GO and SMTP
- Choose Which Events Each Channel Gets
- Alerts for Failed Updates, Failing Checks, New Updates and Users Waiting for Approval
- Test Button for Each Channel

## [0.3.0] - 18th October 2026

- Local Accounts with a One-Time Setup Token on First Start
- Two-Step Sign-In for Local Accounts
- Microsoft Sign-In Set Up on the Settings Page
- Viewer, Operator and Admin Roles, with Entra App Role and Group Mappings
- Users and Account Pages
- reset-admin Command for Lost Access
- /healthz Endpoint and Docker Health Check

## [0.2.0] - 18th October 2026

- Settings Page – Most Settings Can Now Be Changed in the Dashboard
- Server-Side Sessions – Everyone Signs In Again Once After Upgrading

## [0.1.2] - 18th October 2026

- Private Image Pulls Use the Registry Login
- Self-Update Helper No Longer Shown or Left Behind

## [0.1.1] - 18th October 2026

- Dashboard Design
- Handling of Non Docker Hub Images
- Job Log Improvements

## [0.1.0] – 17th October 2026

- Initial Release
