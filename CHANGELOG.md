# Change Log

All notable changes to Docker Manager are recorded here.

## [0.2.0] - 18th October 2026

- Settings Page – Most Settings Can Now Be Changed in the Dashboard
- Saved Secrets Encrypted with an Automatically Created Key
- Registry Logins Managed in the Dashboard
- Server-Side Sessions – Everyone Signs In Again Once After Upgrading
- Settings Changes Shown in History

## [0.1.2] - 18th October 2026

- Private Image Pulls Use the Registry Login
- Self-Update Helper No Longer Shown or Left Behind

## [0.1.1] - 18th October 2026

- Dashboard Design
- Handling of Non Docker Hub Images
- Job Log Improvements

## [0.1.0] – 17th October 2026

- Initial Release
